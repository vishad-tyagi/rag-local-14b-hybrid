3 · Agentic AUTO Router (auto_chain.py)

Intelligence Layer — AutoQueryService
LLM Router (primary)
  • Qwen2.5-14B with structured JSON prompt
  • Returns: modes · confidence · reason · requires_synthesis
  • JSON extracted via regex fallback (multi-candidate scan)
  • Mode validation + clamp to [0.0, 1.0]
  • max_tokens=220 · low latency routing call
Heuristic Fallback Router
  • Term scoring: rag_terms / sql_terms / graph_terms
  • Domain overrides: "balance" → SQL bias
  • Ownership exclusions: graph → 0 if SQL can answer
  • confidence=0.55 (signals fallback to UI)
  • Triggered when LLM router throws any exception
Synthesis Agent
  • Single mode → direct pass-through (no extra LLM call)
  • Multi-mode → LLM synthesis with all pipeline outputs
  • Partial failure: uses successful pipelines, flags missing
  • max_tokens=700 · grounded, no hallucination policy
Router Decision Table

4 · Retrieval Pipelines

Three Independent Query Pipelines
📄 RAG Pipeline — rag_chain.py
1
FAISS Vector Retriever all-MiniLM-L6-v2 embeddings · k=5 · cosine similarity · weight=0.60
2
BM25 Keyword Retriever BM25Retriever.from_documents() · k=5 · weight=0.40 · no extra domain tuning
3
RRF Fusion (k=60) Reciprocal Rank Fusion · weighted score merge · deduplication by (source, content) key · top-5 returned
4
LLM Answer Generation Structured context prompt · SOURCE blocks · max_tokens=800 · strict grounding
5
SSE Token Stream (optional) stream_generate() · per-token yield · special token stripping
🗄️ SQL Pipeline — sql_chain.py
1
LangChain SQL Query Chain create_sql_query_chain · schema introspection via SQLAlchemy · custom SQL_PROMPT with banking domain rules
2
SQL Sanitizer strip_markdown_sql() → remove LLM artifacts · ensure_read_only_sql() → blocklist: INSERT/UPDATE/DELETE/DROP/ALTER/ATTACH/PRAGMA
3
Read-Only SQLite Execution sqlite:///file:?mode=ro&uri=true · fetchall with column introspection · dict row serialization
4
SQL Repair Agent On execution error: schema + failed SQL + error → LLM re-generation → re-execute. One retry cycle.
5
Result Summarizer NL summary from rows preview (max 20) · SQL_SUMMARY_SYSTEM_PROMPT · max_tokens=220
🕸️ Graph Pipeline — graph_chain.py
1
Schema Refresh + Cypher Generation Neo4jGraph.refresh_schema() · CYPHER_GENERATION_PROMPT with 8 pattern templates (A–H) · LangChainMLXLLM
2
Cypher Validator _ensure_read_only_cypher(): blocks CREATE/MERGE/SET/DELETE/DROP/CALL/APOC · requires MATCH or RETURN
3
Neo4j Execution (Bolt) graph.query() via langchain-neo4j · bolt://localhost:7687 · lazy singleton connection
4
Hardcoded Fallback Patterns 7 domain-specific Cypher templates (branch/merchant/account/alert) triggered when LLM query returns empty
5
Result Summarizer GRAPH_SUMMARY_PROMPT · grounded NL answer from graph results · max_tokens=220
↓All pipelines share one loaded MLX model (singleton)

5 · Local ML Runtime — hf_models.py

Apple MLX · On-device Inference
MLXLocalLLM (primary interface)
  • Model: mlx-community/Qwen2.5-Coder-14B-Instruct-4bit
  • Global singleton: _MLX_MODEL / _MLX_TOKENIZER
  • Chat template via tokenizer.apply_chat_template()
  • .answer() → mlx_lm.generate() · blocking
  • .stream_answer() → mlx_lm.stream_generate() · yields tokens
  • Special token stripping: <|im_end|> / <|endoftext|>
LangChainMLXLLM (wrapper)
  • Extends LangChain LLM base class
  • Delegates to MLXLocalLLM._engine
  • Used by: SQL query chain · Graph Cypher chain
  • Pydantic PrivateAttr for _engine isolation
LocalEmbeddings
  • Model: all-MiniLM-L6-v2 (SentenceTransformers)
  • Global singleton: _EMBED_MODEL
  • Device: MPS if available, else CPU
  • normalize_embeddings=True
  • Used by: FAISS ingest + query
Apple Silicon Stack
  • Runtime: Apple MLX framework
  • Device: MPS (Metal Performance Shaders)
  • 4-bit quantized weights (≈ 7 GB VRAM)
  • PyTorch MPS for embeddings
  • Zero GPU cost, fully local
